# Approvals

Committee email from senders who are **not in the neighborhood directory** is held here instead of being forwarded automatically. This one queue covers all committees you moderate, newest first.

## Reviewing a message

- **View message** expands the email. Remote images are blocked until you press **Display images** - image loads can tip off a spammer that the address is live, so only display them when you need to.
- **Approve** forwards the message on to the committee's forwarding members.
- **Reject** discards it. The sender is not notified either way.

If a message disappears or you see "already handled", another moderator got to it first - decisions are shared across everyone who can moderate that committee.

## What you will not see

Obvious spam is classified automatically while a message is in its initial quarantine window and rejected without asking anyone - only mail that is plausibly legitimate reaches this queue. Nothing is lost: automatically rejected messages are retained behind the scenes and recoverable by an administrator if something was filtered wrongly.

If a held message waits too long, moderators are notified in-app (the bell) and eventually by an email digest with a link straight to the message here.
