# Print Directory

Produces printable versions of the neighborhood directory and map, for residents who prefer paper.

## Printing

- **Print Directory** opens a print-formatted directory. Print on **5x8 paper, portrait, scaling 100%**.
- **Print Map** opens a print-formatted map. Print on **8x10 paper, landscape**.

Each opens as a full page laid out for printing - use your browser's Print command from there. The data is live, so a reprint always reflects the current directory.
