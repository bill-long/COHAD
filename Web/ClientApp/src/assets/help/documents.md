# Documents

Upload and organize the files residents see on the Documents page - bylaws, minutes, newsletters, and so on.

## Folders

- **Add Folder** creates a folder; use the up/down arrows to control the order residents see.
- **Rename** edits in place (Enter saves, Escape cancels).
- **Delete** is only possible once a folder is empty - move or delete its documents first.

## Uploading

Drag a file onto the drop zone or use **Choose File**, pick a folder (or "(No folder)" for the Unfiled section), then **Upload Document**. A progress bar tracks the upload.

## Managing documents

Documents are grouped by folder, with unfiled documents in their own section. Clicking a document downloads it - the same thing residents get. **Delete permanently removes the file** after confirmation; there is no undo, so keep an original copy of anything important.
